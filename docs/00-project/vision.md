# Vision

> Canonical продуктовый текст: `PRODUCT.md` в корне репозитория. Этот документ — структурированная выжимка для базы знаний.

## Что такое ViralCloud

ViralCloud (пакет npm: `viral`) — research-and-production dashboard для короткого вертикального видео (YouTube Shorts, Instagram Reels, TikTok). Продукт объединяет поиск трендов, конкурентов, сохранённые референсы и AI-генерацию сценариев в одном рабочем пространстве.

## Пользователи

Solo content creators — блогеры, эксперты, SMM-специалисты, работающие с short-form video. Основной контекст UI — русскоязычные создатели, работающие без agency toolchain.

## Цель продукта

Перевести пользователя от «что сейчас работает?» к «вот мой сценарий» без переключения между соцсетями и инструментами.

Near-term success: free/trial пользователи понимают ценность, упираются в лимиты и переходят на PRO / BUSINESS или покупают token packs.

## Brand personality

Friendly guide — тёплый, понятный, без hype. Эмоциональная цель: relief и momentum (ориентация + действие).

## Anti-references

- Шумные social apps (infinite scroll, attention-bait)
- Generic SaaS dashboards (purple gradients, decorative glass)
- AI-template aesthetics (gradient text, icon-card grids)

## Design principles

1. Guide, don't shout
2. Calm density
3. Content is the hero
4. Earn the upgrade
5. Respect the solo workflow
